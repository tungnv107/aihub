01 · Máy cá nhân

Dùng relay cùng Codex

Bộ cài này cài TDH Relay, runtime đi kèm và cấu hình kết nối cho Codex. Bạn cần có ứng dụng Codex và tài khoản ChatGPT của mình.

  1. Cài ứng dụng Codex từ OpenAI nếu máy chưa có.
  2. Mở PowerShell trên Windows, chạy lệnh cài bên dưới.
  3. Nhập key TDH Relay do quản trị viên cấp khi bộ cài hỏi.
  4. Đóng/mở lại Codex. Đăng nhập ChatGPT nếu chưa đăng nhập, rồi sử dụng như bình thường.

Windows · PowerShell

irm "https://codex.tudonghoa.me/setup.ps1" | iex
Lệnh trên không cài ứng dụng Codex, không tạo tài khoản ChatGPT và không cài Sub2API. Key TDH kích hoạt relay; tài khoản ChatGPT vẫn là tài khoản riêng của bạn.
Cài trên macOS
curl -fsSL "https://codex.tudonghoa.me/setup.sh" | bash

Có bộ cài Intel và Apple Silicon; chưa kiểm thử cài/gỡ trên máy Mac thật.

Gỡ relay và khôi phục cấu hình

Windows

irm "https://codex.tudonghoa.me/setup.ps1?remove=1" | iex

macOS

curl -fsSL "https://codex.tudonghoa.me/setup.sh?remove=1" | bash

Gỡ relay không xóa tài khoản ChatGPT. Dữ liệu chẩn đoán và bản sao cấu hình được giữ lại.

02 · Server / Docker

Kết nối relay với Sub2API

Triển khai gói proxy trên server, kích hoạt key, cấu hình tài khoản upstream và caller API key; sau đó thêm địa chỉ relay vào Sub2API.

  1. Tải gói relay theo manifest và kiểm tra checksum.
  2. Khởi tạo proxy, kích hoạt license rồi chạy Docker Compose theo tài liệu.
  3. Nhập tài khoản/phiên dành riêng cho proxy.
  4. Khai báo base URL và caller key trong kênh Sub2API.
Luồng này tách riêng khỏi bộ cài PowerShell cho Codex cá nhân. Cấp thêm thiết bị cho license nếu bạn dùng cả hai nơi.
Hướng dẫn triển khai Sub2API

Khi cần hỗ trợ

Kiểm tra key còn hạn và đúng số máy. Nếu gặp lỗi đăng nhập ChatGPT, hãy đăng nhập lại trong Codex.

Xuất báo cáo trên Windows

irm "https://codex.tudonghoa.me/diagnose.ps1" | iex

Công cụ tạo file JSON trên Desktop, chỉ gồm phiên bản, số request, mã trạng thái, số lần thử và thời gian xử lý. Không tự gửi file; bạn có thể xem trước rồi tải lên mục Thống kê tại trang khách hàng.

TDH Relay · Relay desktop chạy trên máy của bạn. Kích hoạt và gia hạn license cần kết nối server. Hiệu quả quota chưa được chứng minh tương đương tuyệt đối relay tham chiếu.
